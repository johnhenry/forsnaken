# Ideas

- Network play: a snake steered by commands over a WebSocket or WebRTC.
- End conditions: last snake standing; a scoreboard on game over.
- Variable apples (value shown by size or color).
- Sound effects on score and death.
- Other renderers: HTML, SVG, the console.
- More games in the same style: Pong, Breakout, Tetris, Bomberman, Flappy Bird.
